# Кулинарная соцсеть (Culinary Social Network)

## Project Name
**Кулинарная соцсеть** — веб- и мобильное приложение для публикации, поиска мультимедийных рецептов и социального взаимодействия пользователей.

## Description
Проект представляет собой социальную сеть для любителей кулинарии, объединяющую функции публикации рецептов (текст, фото, видео) и социального взаимодействия (подписки, комментарии, фотоотчёты). Ключевое конкурентное преимущество — сочетание формата соцсети с утилитарными инструментами для готовки: умный поиск с исключением аллергенов, автоперерасчёт порций, генератор списка покупок и режим Wake Lock (блокировка затухания экрана). Приложение решает проблему разрозненности кулинарного контента и неудобства использования классических сайтов с рецептами на кухне. Целевая аудитория — повседневные кулинары, кулинарные креаторы и люди со специфическим питанием (аллергии, диеты).

## Installation
На данный момент проект находится на стадии проектирования (Лабораторная работа №1). Инструкция по установке будет добавлена после реализации MVP.

Планируемые шаги установки:
1. Клонировать репозиторий: `git clone https://github.com/katekasyanik/zvaniy_yuzin-project.git`
2. Установить зависимости (будут указаны в `requirements.txt` или `package.json`).
3. Настроить подключение к базе данных.
4. Запустить сервер разработки.

## Usage
После установки приложение позволит:
- Искать рецепты с фильтрацией по ингредиентам и исключением аллергенов.
- Автоматически пересчитывать количество ингредиентов под нужное число порций.
- Генерировать список покупок на основе выбранных рецептов.
- Публиковать собственные рецепты (текст, фото, видео) с настройкой приватности.
- Подписываться на других пользователей и оставлять комментарии с фотоотчётами.

Скриншоты будут добавлены после разработки прототипа.
