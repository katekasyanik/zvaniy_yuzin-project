# Кулинарная соцсеть

Добро пожаловать на сайт проекта **«Кулинарная соцсеть»** — веб- и мобильного приложения для публикации, поиска рецептов и социального взаимодействия пользователей.

## О проекте

Проект представляет собой социальную сеть для любителей кулинарии, объединяющую функции публикации рецептов (текст, фото, видео) и социального взаимодействия (подписки, комментарии, фотоотчёты). Ключевое конкурентное преимущество — сочетание формата соцсети с утилитарными инструментами для готовки: умный поиск с исключением аллергенов, автоперерасчёт порций, генератор списка покупок и режим Wake Lock.
